# ADEM Investor Website

A deploy-ready Next.js landing page for ADEM.

## Local preview

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

1. Create a new GitHub repository.
2. Upload all files in this folder.
3. Go to Vercel → Add New Project → Import the GitHub repository.
4. Use default Next.js settings.
5. Deploy.
6. Add `ademtrust.ai` in Vercel → Project → Settings → Domains.
7. Update GoDaddy DNS using Vercel's provided records.
